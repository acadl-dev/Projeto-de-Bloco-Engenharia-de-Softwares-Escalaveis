## 📌 Sobre o projeto

O **Finora** é o sistema desenvolvido como parte do Projeto de Bloco de Engenharia de Softwares Escaláveis.

Este repositório funciona como um ponto central para organizar os principais entregáveis de cada etapa, incluindo:

- 💻 Código-fonte do **Backend**
- 🖥️ Código-fonte do **Frontend**
- 📚 Documentações técnicas
- 🎥 Demonstrações do sistema
